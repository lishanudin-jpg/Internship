# Forno Pizza Client

The customer-facing ordering site is built with React and Vite.

## Development

Install dependencies and start the API in `../server` first. Then run:

```powershell
npm install
npm run dev
```

Vite serves the site locally and proxies `/api` requests to `http://localhost:5001`.

## Checks

```powershell
npm run build
npm run lint
```
